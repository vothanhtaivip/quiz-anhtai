Khi BẬT: Học sinh bắt buộc phải nhập đúng mật khẩu mới vào làm bài được.

Chế độ Chống Gian Lận (Anti-cheat)

Tắt tạm thời nếu Admin muốn chuyển tab test thử đề mà không bị trừ điểm.

Mật Khẩu Đăng Nhập Admin
💡 Hướng dẫn nhét đề bằng Word / Text thô cực dễ:
Bạn chỉ cần copy đề từ Word, Google Docs hoặc Notepad rồi dán vào khung dưới.
Định dạng hỗ trợ:
Câu 1: Câu hỏi ở đây?
A. Lựa chọn 1
B. Lựa chọn 2
C. Lựa chọn 3
D. Lựa chọn 4
Đáp án: B (hoặc Đáp án đúng: B, hoặc Key: B)
Giải thích: Giải thích nếu có (tùy chọn)
Định dạng JSON chuẩn:
Mảng các object: [{"tag":"Chủ đề","q":"Câu hỏi?","opts":["A","B","C","D"],"ans":1,"explain":"Giải thích"}]
Trong đó: ans là chỉ số (0=A, 1=B, 2=C, 3=D).
