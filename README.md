  - 25 câu hỏi trắc nghiệm ngẫu nhiên, 30 giây/câu.

- ✍️ **Phần 2 Tự Luận**: Lật mở mảnh ghép node bí mật, đếm ngược 20 phút, giới hạn từ 40–240 từ.
